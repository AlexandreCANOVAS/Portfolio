# Portfolio - Alexandre Canovas

Portfolio personnel orienté **alternance IT** (support informatique / maintenance systèmes & réseaux junior), conçu pour présenter un profil sérieux, opérationnel et employable en entreprise.

## Objectif

Convaincre un recruteur IT pour une alternance Bac+2 (CESI) sur des missions de :

- Support utilisateur (helpdesk / support N1)
- Maintenance postes et environnements Windows
- Bases réseau (IP, DNS, DHCP, TCP/IP)
- Développement web front-end (HTML/CSS/JavaScript)

## Profil en 30 secondes

- Reconversion vers l'IT après un parcours en sécurité terrain (gendarmerie + sécurité privée)
- Qualités métier : rigueur, discipline, sens du service, autonomie
- Orientation forte vers les métiers support et systèmes/réseaux

## Points forts du portfolio

- Design futuriste professionnel, responsive (desktop + mobile)
- Mode sombre
- Animations avancées :
  - Intro type terminal au chargement
  - Animations au scroll section par section
  - Effet constellation réseau en arrière-plan
- Édition directe du contenu depuis le site (panneau "Editer")
- Contenu aussi modifiable dans `content.js`

## Stack technique

- HTML5
- CSS3
- JavaScript (vanilla)
- Git / GitHub

## Lancer le projet en local

1. Cloner le repo
2. Ouvrir le dossier dans VS Code
3. Ouvrir `index.html` dans le navigateur

Option recommandée : extension **Live Server** pour le rechargement automatique.

## Modifier le contenu

### Option 1 (la plus simple)

- Cliquer sur **Editer** directement sur le site
- Mettre à jour le JSON
- Cliquer sur **Appliquer**

### Option 2 (fichier)

- Modifier `content.js` (hero, about, skills, projects, certifications, goal, contact)
